📖 バッジ・色分けの説明

🎨 色の意味(共通ルール)

赤 = 危険・要注意 — 無断キャンセル歴など、必ず確認してほしいもの
濃いオレンジ(注意・強) = 当日キャンセルなど、赤ほどではないが要注意なもの
オレンジ(注意) = 通常キャンセルの蓄積など、様子を見てほしいもの
青(情報) = 操作・参照可能な項目 — 電話番号(タップで発信)など
緑(良好) = リマインド実施済みなど、対応が完了した状態
グレー(中立) = 件数バッジなど、警告ではない参考情報

📋 予約者リスト

再2リピーター（再来）。キャンセル済みを除く実予約が2回以上ある人。電話番号がある予約は電話番号で、電話番号が無い予約（HPB経由）は氏名だけで数えます（HPBの場合は同姓同名の別人が混ざる可能性があります）。クリックするとその人だけ検索できます
⚠️無断2この人は過去に無断キャンセルが2回ある(要注意)
🟠当日2この人は過去に当日キャンセルが2回ある(振替は含まない)
🔁重複?同じ日・同じ名前・同じ電話番号の予約が他にもある。二重登録の可能性
👥同名?同じ日・同じ名前だが電話番号が違う予約が他にもある。別人の可能性
キャンセル済キャンセルメールが届いた予約。取消線表示になり、本日サマリー・要注意アラートの対象外
行全体が薄い赤+左に赤帯 = 無断キャンセルの警告対象
行全体が薄い赤+左に赤帯 = 🔁重複?の対象(無断警告と同じ色。原因はマウスオーバーの説明文で判別)
行全体が薄いオレンジ+左にオレンジ帯 = 👥同名?の対象
行がグレーで文字が薄い = 予約日時が過去(すでに来店済み想定)
📞電話・✉️メール のチェック列(今日以降の予約のみ) = リマインド実施済みかどうか。チェックすると実施日時を記録
🟠当日・🚫無断 のチェック列 = チェックすると各リストへ登録(電話キャンセル・無断キャンセルの手動登録用)

HPB ホットペッパービューティー経由の予約

HPBメニュー欄の先頭に付きます。サロンボードから届く予約通知を取り込んだものです
📋サロンボードで確認電話番号の代わりに出ます。HPBの通知メールには電話番号が載らないため、かける前にサロンボードの予約詳細で番号を確認してください(予約番号は行をタップした詳細に出ます)
—✉️メール列がこの表示 = メールアドレスも通知に載らないため、メールリマインドは対象外です。「📋リマインド未」の判定も📞電話リマインドだけで行います
検索欄に「hpb」「サロンボード」と入れると、HPB経由の予約だけに絞り込めます
電話番号が無いため、予約不可リストとの照合・重複チェックは氏名のみで行われます(同姓同名は別人の可能性があるため 👥同名? として出ます)

🔎 同じお客様かどうかの見分け方

無断キャンセル歴・当日キャンセル歴・予約不可リストとの照合は、電話番号・メールアドレス・氏名のいずれかで行います
電話番号どうし（またはメールアドレスどうし）を突き合わせられる場合は、それで判定します。番号が違えば同姓同名でも別人として扱います
🚷予約不可?末尾の「?」は氏名だけが一致したことを表します。電話番号もメールアドレスも無い予約（HPB経由など）で出ます。同姓同名の別人の可能性があるので、サロンボード等で本人か確認してください

📝 当日キャンセルの理由

🤒体調不良（本人）グレー＝やむを得ない事情。記録は残りますが、予約不可の回数には数えません（体調不良・家族看病・交通機関・悪天候・冠婚葬祭）
😴予約忘れ・寝坊オレンジ＝自己都合。2回で予約不可の確認対象になります（仕事・予約忘れ・都合・理由不明・その他）
⚪ 理由を選ぶ点線＝未設定。メールから自動判定した分は理由が分からないため、安全側で「カウント対象」になります。クリックで選べます
🟠当日3(情状2)「(情状N)」は、やむを得ない事情として回数に数えなかった件数です。総数は必ず表示されるので、乱用パターンも見逃しません
